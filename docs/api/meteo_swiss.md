# meteo_swiss

Download historical and recent measurement data (10-minute, hourly, daily)
of MeteoSwiss stations from the MeteoSwiss open data portal (OGD), get the
current measurements of all automatic weather stations, and find the nearest
station for a given location and sensor type.

See {doc}`../examples/meteo_swiss` for usage examples.
