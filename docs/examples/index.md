# Examples

Usage examples for all pyedautils modules. See {doc}`../api/index` for the full API reference.

- {doc}`data_io` — Save and load data in CSV, pickle, JSON
- {doc}`data_quality` — Gaps, stuck values, outliers and quality flags
- {doc}`geopy` — Geocoding, coordinate conversion, altitude lookup
- {doc}`plots` — Visualizations (daily profiles, heatmaps, energy signature, seasonal, comfort and Mollier h,x-diagram, statistics, gradients, solar influence)
- {doc}`data_prep` — Data preprocessing (season, sun position, gradients, solar influence)
- {doc}`weather` — Swiss weather data (MeteoSwiss stations and current data, Agrometeo.ch downloads)
