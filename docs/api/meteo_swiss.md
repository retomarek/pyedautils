# meteo_swiss

Current measurements of all MeteoSwiss automatic weather stations, the
nearest station for a given location and sensor type, and daily SwissMetNet
values (temperature, global radiation) from the MeteoSwiss Open Government Data.

See {doc}`../examples/meteo_swiss` for usage examples.
