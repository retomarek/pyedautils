# open_data_ch

Monthly degree-day series from Swiss open data: the population-weighted
Swiss heating and cooling degree days of the BFE (since 1980) and the
heating degree days / accumulated temperature differences of the Stadt
Zürich (since 1864). Both serve as reference series for
{doc}`degree_days`.

See {doc}`../examples/open_data_ch` for usage examples.
